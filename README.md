# 🌾 เครือข่ายกสิกรรมธรรมชาติ จังหวัดนครสวรรค์
### Nakhon Sawan Natural Agriculture Network Hub

ระบบบริหารจัดการฐานข้อมูลผลผลิต สมาชิก และ E-Catalog กลางสำหรับ **เครือข่ายกสิกรรมธรรมชาติ จังหวัดนครสวรรค์** เชื่อมโยงผลผลิตอินทรีย์ ปัจจัยการผลิต By-product (ถ่านไบโอชาร์, น้ำส้มควันไม้, น้ำหมักชีวภาพ) และเมล็ดพันธุ์พื้นบ้านจาก 15 อำเภอในจังหวัดนครสวรรค์

---

## ✨ จุดเด่นสำคัญของระบบ (Key Highlights)

### 1. 📦 การจัดกลุ่ม SKU ข้ามแปลง (Cross-Farm SKU Aggregation)
* **หน้าตลาดกลาง (E-Catalog):** รวมผลผลิตชนิดเดียวกันจากหลายแปลงไว้ด้วยกัน เช่น เมื่อดู *"ถ่านไบโอชาร์"* หรือ *"น้ำส้มควันไม้"* ระบบจะแสดงให้เห็นทันทีว่ามีแปลงใดใน 15 อำเภอที่มีผลผลิตนี้บ้าง พร้อมเปรียบเทียบราคาและโซนที่ตั้ง
* **การแนะนำเกื้อกูลกันในเครือข่าย:** ในหน้ารายละเอียดผลผลิตของแปลงหนึ่ง จะมีแถบ *"ผลผลิตประเภทนี้จากพี่น้องแปลงอื่นในเครือข่าย"* เพื่อส่งเสริมวิถีเกื้อกูลกันในกลุ่ม

### 2. 👵 การออกแบบเพื่อผู้สูงอายุ (Senior-Friendly Accessibility)
* **ปุ่มสลับขนาดตัวอักษร 3 ระดับ (ก ปกติ | ก ใหญ่ | ก ใหญ่พิเศษ):** บันทึกการตั้งค่าลงในโปรไฟล์สมาชิกอัตโนมัติ
* **ปุ่มสัมผัสขนาดใหญ่พิเศษ ($\ge 54\text{px}$):** สีสันคมชัด คอนทราสต์สูง ไม่กดพลาด
* **ฟอร์มเพิ่มผลผลิต 1 นาที (Low-Friction Wizard):** เน้นการกดเลือกการ์ด (Tap & Select) แทนการพิมพ์ยาวๆ

### 3. 🔒 ความปลอดภัยป้องกันมิจฉาชีพ (Anti-Scam & Zero Data Leakage)
* **ซ่อนเบอร์โทรศัพท์และ LINE เป็นค่าเริ่มต้น:** ตัดข้อมูลเบอร์โทรศัพท์และ LINE ID ออกตั้งแต่ฝั่ง Service/Data Layer หากเจ้าของแปลงยังไม่ได้เปิดอนุญาต (ปลอดภัย 100% จากการ Inspect ดู Source Code)
* **พิกัดแปลงแบบโซนรัศมี (Safe Zone):** แสดงเพียงขอบเขตรัศมีคร่าวๆ (3-5 กม.) บนหน้าเว็บสาธารณะ โดยเก็บพิกัดจริงไว้เฉพาะฐานข้อมูลภายในเครือข่ายเท่านั้น

### 4. 📸 ระบบย่อและ Crop รูปภาพฝั่งผู้ใช้ (Client-side Image Optimizer)
* ย่อภาพถ่ายความละเอียดสูงจากกล้องมือถือ ($5\text{--}10\text{MB}$) เหลือเฉลี่ย $150\text{--}250\text{KB}$ ทันทีบนเบราว์เซอร์ ช่วยประหยัดพื้นที่จัดเก็บและประหยัดเน็ตมือถือ
* มีเครื่องมือครอปรูปภาพอย่างง่าย (Simple Mobile Cropper) ให้เกษตรกรครอบเฉพาะจุดเด่นได้ทันที

### 5. 🤝 ระบบผู้ช่วยแอดมินลงข้อมูลแทน (Assisted Entry & Traceability)
* สมาชิกสูงอายุสามารถกดปุ่ม **"ขอให้แอดมินช่วยลงข้อมูลแทน"** ได้ในคลิกเดียว
* ทุกการแก้ไขข้อมูลแทนสมาชิก จะมีการบันทึก **Audit Log** ระบุตัวตนแอดมิน เวลา และรายละเอียดอย่างโปร่งใส

### 6. 🛡️ แผงควบคุมแอดมินเครือข่าย (Admin Center)
* ตรวจสอบและอนุมัติสมาชิกใหม่ด้วย **"รูปหน้าตรงสมาชิก"** เพื่อยืนยันตัวตน
* เพิ่ม/ลด/แก้ไข **หมวดหมู่และชนิดผลผลิต (Standard SKU Tags)** ได้อย่างอิสระตามมติของกลุ่ม

## 🛠️ โครงสร้างเทคโนโลยี (Tech Stack)

* **Framework:** [Next.js 14](https://nextjs.org/) (App Router, TypeScript)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (โทนสีธรรมชาติ ดินอบอุ่น สไตล์กสิกรรมธรรมชาติ)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Image Processing:** HTML5 Canvas Client-side Resizer & Aspect Ratio Cropper
* **Accessibility:** Custom React `FontSizeContext` with LocalStorage & Profile synchronization
* **Testing & Quality Assurance:** [Vitest](https://vitest.dev/) (Unit, Security & RBAC), [Puppeteer](https://pptr.dev/) (End-to-End Headless Smoke Tests)
* **Account กลางของเครือข่าย:** `agrinature.network.nsw@gmail.com`

## 🚀 วิธีการติดตั้งและรันระบบ (Getting Started)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รันโหมดทดสอบในเครื่อง (Development)
```bash
npm run dev
```
เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000)

### 3. รันชุดทดสอบถดถอยอัตโนมัติ (Automated Regression Testing)
โปรเจกต์มีชุดทดสอบอัตโนมัติเพื่อป้องกันบั๊กย้อนกลับ (Regression) เมื่อพัฒนาฟีเจอร์ใหม่:
```bash
# ตรวจสอบ Business Logic, HMAC Cryptography, สิทธิ์ RBAC, และ Data Privacy (< 0.5 วินาที)
npm test

# จำลองการทดสอบบนเบราว์เซอร์จริงด้วย Puppeteer (Admin Gate, Login, Sign Out) (~3-5 วินาที)
npm run test:e2e
```

### 4. ตรวจสอบการ Build (Production Build)
```bash
npm run build
npm run start
```

## 🔒 การตั้งค่าความปลอดภัยระดับเซิร์ฟเวอร์ (Server Security Environment)

ระบบใช้การยืนยันตัวตนแอดมินระดับ Server-Side ผ่าน HMAC-SHA256 Signed Cookies ป้องกันการแฮกหรือดูรหัสผ่านจากเบราว์เซอร์ 100% โปรดกำหนดค่าใน `.env.local` หรือบน Vercel Dashboard:

```bash
# รหัสผ่านสำหรับเข้าศูนย์แอดมิน (ห้ามใส่ NEXT_PUBLIC_ เด็ดขาด)
ADMIN_PASSCODE=your_secret_passcode

# Secret Key สุ่มยาวๆ สำหรับลงลายมือชื่อ HMAC Session Cookie
ADMIN_SESSION_SECRET=your_super_secret_hmac_key_32chars

# (ทางเลือก) LINE User ID ของแอดมิน คั่นด้วยจุลภาค สำหรับล็อกอินอัตโนมัติ
ADMIN_LINE_USER_IDS=U11111111111111111111111111111111
```

## 📱 โครงสร้างหน้าจอหลัก

* `/` : หน้าแรกนำเสนอของดีเครือข่าย สถิติ 15 อำเภอ และพรีวิวแอปพลิเคชันมือถือ
* `/catalog` : ตลาดนัด E-Catalog (สลับดูตามกลุ่ม SKU หรือดูรายชิ้น กรองตามอำเภอในนครสวรรค์)
* `/catalog/[productId]` : หน้ารายละเอียดผลผลิต พร้อมช่องทางติดต่อปลอดภัย และแนะนำผลผลิตจากเพื่อนสมาชิก
* `/farms` : สารบบแปลงกสิกรรมธรรมชาติใน 15 อำเภอ
* `/farms/[farmId]` : หน้าโปรไฟล์แปลง เรื่องเล่า แผนที่โซนรัศมีปลอดภัย และแคตตาล็อกของแปลง
* `/member/dashboard` : แดชบอร์ดสมาชิกเกษตรกร จัดการเบอร์โทร (เปิด/ปิด) และปุ่มขอความช่วยเหลือ
* `/member/add-product` : วิซาร์ดเพิ่มผลผลิต 1 นาที พร้อมระบบย่อรูปภาพ
* `/admin` : แผงควบคุมแอดมิน (อนุมัติสมาชิก, คิวช่วยเหลือ, จัดการหมวดหมู่ SKU, Audit Log)
* `/news` : กระดานข่าวสาร งานเอามื้อสามัคคี พร้อมปุ่มแชร์ลง LINE และ Facebook
* `/manual` : คู่มือการใช้งานออนไลน์ 3 บทบาท (ผู้บริโภค, สมาชิกเกษตรกร, แอดมินเครือข่าย)
